## Licensure experience log

The [licensure program](./security-systems-licensure) turns on a statutory requirement of
**6,720 hours** of documented hands-on experience
([N.J.A.C. 13:31A-3.1](https://www.law.cornell.edu/regulations/new-jersey/N-J-A-C-13-31A-3-1)).
Nobody will reconstruct that record for you years later. Log it as it happens.

| Period | Employer / client | Hours | Nature of work | Verified by |
| :-- | :-- | --: | :-- | :-- |
| | | | | |

**Hours logged: 0 / 6,720**

Record only hours "working with tools in the installation, alteration, or repair of wiring
for fire alarms, burglar alarms, and/or electronic security systems" — that is the language
of the rule, and it is what the Committee will ask you to substantiate. Keep the underlying
records (invoices, timesheets, supervisor contacts) somewhere durable; this table is an
index to them, not a substitute.
